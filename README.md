#### Projetos em destaque

- **[thor](https://github.com/edsoncantuaria/thor)** — Workspace desktop multi-agente
  (Tauri): roda Claude Code, Codex, Copilot e shells lado a lado. O mais maduro do
  perfil — CI com 4 workflows, testes unitários e e2e, docs de contribuição e segurança.

- **[dndai](https://github.com/edsoncantuaria/dndai)** — Plataforma de RPG solo com
  Mestre de IA (Next.js + Gemini, backend Fastify/PostgreSQL/Temporal). O projeto
  pessoal mais ambicioso em escopo: criação de personagem, combate tático, geração de
  imagem e narração por voz.

- **[vtt-edson](https://github.com/edsoncantuaria/vtt-edson)** — Mesa virtual de RPG
  (VTT) em tempo real: backend Laravel/PHP + frontend React/Pixi.js para renderização
  de mapas e tokens.

- **[spotlight](https://github.com/edsoncantuaria/spotlight)** — Launcher estilo
  Raycast/Spotlight para Linux (Rust + Tauri): busca universal, clipboard, extensões.
  Releases publicados (.deb/.AppImage), CI e changelog.

- **[termo-online](https://github.com/edsoncantuaria/termo-online)** — Jogo de
  palavras em português com modo ranqueado e salas em tempo real (WebSocket).
  Python, CI, testes e2e, deploy via Docker.

- **[iamlive](https://github.com/edsoncantuaria/iamlive)** — App de check-in de
  segurança pessoal: se o prazo expira, envia alerta automático via WhatsApp aos
  contatos de confiança. Mobile (Expo/React Native) + backend Node.js (Baileys/Socket.io).
